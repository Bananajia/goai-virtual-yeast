# Evidence registry

`registry.json` is the non-destructive index for historical experiment evidence.
It does not move, rewrite or reinterpret the frozen experiment directories.  It
records only:

- experiment status and a short validity boundary;
- replacement lineage when a result was superseded;
- a relative aggregate-document reference and its SHA-256;
- a small set of frozen aggregate metrics used as replay checks.

The registry never contains sample identities, drug/strain identities,
predictions, protein vectors or machine-specific private-data locations.

`loss-ablation-v1/RESULTS.md` is a deliberately compact release-safe evidence
source. Unlike records that point to the optional historical tree, it ships with
the clean code layer and supports an eight-scalar aggregate replay. Its status is
`VALIDATED_REJECTED`: this makes the loss comparison auditable without implying
that private 384-coordinate model training can run from the public package.
The corresponding clean-integration checks are recorded in
`loss-ablation-v1/RELEASE_TEST_RECORD.md`.

`structure-generalization-v1/RESULTS.md` is the release-safe evidence source
for the second completed follow-up. It records the 37-drug all-ITT result, the
22-covered/15-missing stratification, the three candidate definitions and
frozen paired deltas. The corresponding Adapter is aggregate-only: it does not
ship the private response matrix, identities, predictions or model state, and
does not claim private-pilot retraining.
Its clean-integration checks are recorded in
`structure-generalization-v1/RELEASE_TEST_RECORD.md`.

`chemcpa-nonlinear-v1-v2/RESULTS.md` combines the two nonlinear-composition
protocols into one release-safe aggregate source. It preserves the essential
input boundary: v1 directly uses an exact-context measured-control latent and is
conditional only, whereas v2 holds the predictor control block at zero and is a
development follow-up rather than an independent confirmation. The record
freezes the all-ITT M0/C0/C1/N1 means, paired promotion gate, 37/22/15 population
and non-gating CSV zero-rounding qualification. It contains no entity-level
artifacts or machine-local locations and does not claim original CPA/chemCPA
reproduction. Clean-integration checks are recorded in
`chemcpa-nonlinear-v1-v2/RELEASE_TEST_RECORD.md`.

`pubchem-structure-confirmatory-v1/RESULTS.md` freezes the independently replayed
PubChem-first confirmation as anonymous aggregates. It records the 4,422/zero-tie
coordinate contract, 37/25/12 population split, all-37 M0/C0/M1/M2/M3 Raw-FC
means in both grouped-OOD scenarios, the three no-promotion decisions and the
300/60/576/216 replay counts. It contains no entity mapping, molecular string,
fold row, prediction, feature vector or fitted parameter. Clean-integration
checks are recorded in
`pubchem-structure-confirmatory-v1/RELEASE_TEST_RECORD.md`.

`public-causal-residual-v1/RESULTS.md` is byte-identical to the audited
aggregate result for the public 23-axis signed-representation pilot. The
Adapter verifies 39 anonymous counts, fold-macro metrics, fold-direction
witnesses and replay counts. It ships no public-to-competition entity join,
prompt/transcript, causal-chain payload, mechanism-axis vector, protein
response, prediction or fitted parameter. The closed commercial authoring seam
and its non-reproducible service-snapshot boundary are disclosed separately in
`external_resources/manifest.json`.

`public-similarity-prototype-v1/RESULTS.md` is byte-identical to the audited
aggregate result for hard clustering, soft dual-view neighbours and partial
pooling. Its Adapter verifies 43 all-ITT coverage and comparison scalars while
shipping no entity mapping, molecular/genome feature, neighbour list, response
vector, prediction or fitted weight. Both new receipts are stored beside their
sources as `RELEASE_TEST_RECORD.md`.

`code_inventory.json` is generated by `build_code_inventory.py`. It currently
indexes every historical experiment directory and reports only relative paths,
family, file counts, test counts, report counts, and evidence status. It is the
migration map for code that has not yet received a unified Adapter.

These release sources deliberately omit identities, prompts/transcripts,
entity mappings, response or protein vectors, predictions, fitted parameters,
bootstrap draws and machine-local paths. `LegacyEvidenceReplay` verifies each
source hash before parsing any scalar.

## Status meanings

| Status | Meaning |
|---|---|
| `VALIDATED_BASELINE` | Frozen aggregate evidence for a formal sanity or core baseline. |
| `VALIDATED_AUDIT` | Reproducible engineering/data audit; not necessarily a predictive model. |
| `VALIDATED_CONDITIONAL` | Reproducible only under the stated inference/estimand condition. |
| `VALIDATED_SCOPED` | A narrow scientific conclusion is reproducible; broader promotion is not. |
| `VALIDATED_REJECTED` | The experiment is valid and its frozen candidate was rejected. A negative result is still golden evidence. |
| `PARTIALLY_VALIDATED` | Only the explicitly named structural evidence remains valid. |
| `INVALIDATED` | Historical metrics must not be used as golden evidence. Follow `replacement`. |
| `BLOCKED_IDENTIFIABILITY` | A preflight correctly stopped numeric execution because the hypothesis was not identifiable. |
| `BLOCKED_SOURCE_MISSING` | Narrative references exist, but executable source/receipt is missing; no reproducibility claim is allowed. |
| `PENDING` | Protocol is registered, but no audited aggregate outcome exists; zero golden metrics are allowed. |

## Replay Interface

```python
from pathlib import Path
from experiment_core.legacy_evidence import LegacyEvidenceReplay

receipt = LegacyEvidenceReplay().verify(
    documents_root=Path("/path/to/GOAI-virtual-yeast-project")
)
assert receipt.status == "PASS"
```

The Adapter verifies the aggregate file hash **before** extracting metrics.  A
hash change, missing source, missing metric or changed value fails closed.  The
same implementation also satisfies the common `Experiment.run(RunContext)`
Interface and writes only aggregate counts/metrics through the shared report
writer.

The four late knowledge/genome experiments were copied non-destructively into
the long-lived Documents project on 2026-08-10. Their registry records now use
the persistent `documents` root. The original workspace copies remain unchanged.
